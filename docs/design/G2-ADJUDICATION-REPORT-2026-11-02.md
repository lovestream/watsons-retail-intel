## 三、根因

原规则只认「美妆个护 × 即时零售」的交集，把**平台侧基础设施动作**
（投入/补贴/入驻/履约）全推到 reference，而这些对屈臣氏电商决策
价值比美妆新闻更大。

同时"有动作词就放行"过粗，把餐饮厨房、会员卡规则、3C 品牌合作也放进来了。

## 四、规则修正内容

| 改动 | 说明 |
|---|---|
| 新增 `PLATFORM_INVEST` + `PLATFORMS_CORE` | 平台投入/补贴/入驻/履约/供应链 → **main** |
| 新增 `BIG_RETAILER` | 苏宁/国美/永辉等实体零售商入驻平台 → **main** |
| 新增 `DEVICE_BRANDS`（置于最前） | vivo/华为/小米/智能眼镜等 → **reject** |
| 新增 `BRAND_MODEL` | 美妆品牌 DTC/直营/重启 → **main** |
| `NOISE_SUBJECT` 补充 | 厨房/餐饮/生鲜/家宴/会员卡/积分 → **reject** |
| `STOCK_SUBJECT` 补 `研报`/`估算` | 汇丰研报这类漏网 → **reject** |
| `OPERATIONS` 补营销动作 | 盛典/快闪/联名/首店/主题店 |
| `BEAUTY` 补品牌 | 博倩叶/Boscia/玉泽/薇诺娜/润百颜 |
| 主体判定改「文中最先出现」| 修正「苏宁…与美团」被误判为美团主体 |
| 动作新增 `收购重启` 族 | Boscia 三条变体归并 |
