### B 类：30 条年份/格式差异

文件：`B_year_missing_or_format.csv`

**核心问题**：原文只写「10月28日」（无年份），模型补成 `2025-10-28`。
Issue 明确禁止"从日期值倒推出原文缺失年份"。**这 30 条应判为年份来源不明。**

其中 `2025-10-28` 组（4 条）尤其可疑：2026 年的文章引用「10月28日」，
被推断为 2025 年，需要人确认是否原文本身就是旧闻回顾。
