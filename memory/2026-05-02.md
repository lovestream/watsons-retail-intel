## source_url_monitor Bootstrap 模式 (Session 5)

### 问题
第一次运行时 all URLs are "newly_discovered", 造成假新鲜度。

### 修复
1. `load_seen_urls()` 返回 `(seen_dict, is_bootstrap)` 元组
   - empty/missing ledger → `is_bootstrap=True`
   - 有数据的 ledger → `is_bootstrap=False`
2. `main()` 接收 `is_bootstrap` 并传给 `monitor_source()`
3. Bootstrap 模式下发现的 URL → `freshness_status=bootstrap_seen`（不是 `newly_discovered`）
4. 第二次运行及以后 → 只有 ledger 中不存在的新 URL 才标 `newly_discovered`
5. 摘要统计新增: `bootstrap_mode`, `bootstrap_seen_count`, `newly_discovered_count`, `ledger_size_after`

### Filter 修改
- `bootstrap_seen` 在 `compute_rule_score()`: -2分（历史URL不可靠）
- `bootstrap_seen` 在 `decide_final_pool()`: 绝不进 cleaned，最高 reference
  - core_hit + score≥5 → reference(历史背景)
  - score≥6 → reference(历史背景)
  - score≥3 → reference
  - score<3 → reject

### 测试结果 (空ledger)
- `is_bootstrap=True` ✅
- 所有URL都标记 `bootstrap_seen` ✅
- `newly_discovered_count=0` ✅
- 有数据ledger → `is_bootstrap=False` ✅
