## 判断标签说明
| 标签 | 含义 |
|---|---|
| A | 必须关注—影响平台流量/费用/规则/销售结构 |
| B | 本周跟进—有业务机会，需团队验证 |
| C | 趋势观察—暂不行动，持续关注 |
| R | 风险预警—可能对销售/利润/履约造成负面影响 |
| K | 竞对可借鉴—可转化为屈臣氏动作 |
| X | 需跨部门协同—需采购/营运/商品/门店/BD推进 |
