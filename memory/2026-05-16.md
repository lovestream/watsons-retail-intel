### 第三轮优化（深度检查）

**品观日期提取修复** — 品观首页日期有两种格式："16小时前" 和 "2026-05-15"。修改 `date_pattern` 为 OR 模式 `(\d+)\s*(小时|分钟|天)\s*前|(\d{4}[-/]\d{2}[-/]\d{2})`，同时修复 `_extract_date_from_text` 函数处理 OR 模式产生的 None groups。

**`_extract_date_from_text` 函数修复** — 原函数在处理 OR 模式时会因 groups 包含 None 值而失败（int(None) → ValueError）。修复后：
- 相对日期：检查 groups[0] is not None
- 绝对日期(3 groups)：检查 groups[0/1/2] 都不为 None
- 绝对日期(OR 模式)：检查 groups[2] is not None，解析日期字符串
- 单 group：检查 groups[0] is not None
