# Muse 独立版｜即时零售 × 个护美妆经营情报系统

> 本目录是 Muse 网页端独立实现，与原 QwenPaw/Python 系统平行运行、互不依赖；GitHub 仅作规则与经授权成果的共享平台。
> 总任务书：[`MASTER_GOAL.md`](./MASTER_GOAL.md)（唯一总体目标，未经授权不改）。

## 文件索引

| 文件 | 用途 |
|---|---|
| `PROJECT_RULES.md` | 提炼后的业务硬规则（边界、证据、分级、报告门槛） |
| `SOURCE_STRATEGY.md` | 来源分层与 Muse 原生搜索方法、查询矩阵 |
| `DATA_SCHEMA.md` | 事件字段、去重规则、经营分析结构、报告章节 |
| `OPERATIONS.md` | 运行节奏、单次流程、状态、恢复与复盘 |
| `TEST_PLAN.md` | 能力实测记录与 S1/S2/S3 验收用例 |
| `CHANGELOG.md` | 每次迭代记录 |
| `events/` | 月度事件账本（公开来源事实与链接） |
| `runs/RUNLOG.md` | 每次运行的窗口、计数与状态 |
| `reports/` | 经审校可公开的试运行/周期报告 |
