# SOURCE_STRATEGY — Muse 独立版来源与搜索方法

> 版本：v1.0（2026-10-24）。继承原 `config/sources.yaml`、`source_packs.yaml`、`search_policy.yaml`、`keywords.yaml` 的业务意图，改为 Muse 原生搜索实现，不照搬爬虫/RSS/API 管线。

## 1. 搜索工具与分工（Muse 原生）

| 手段 | 用途 | 说明 |
|---|---|---|
| `browser.search`（含 news 竖版） | 主发现引擎 | 按下方查询矩阵组合搜索；结果带来源与时间线索 |
| `browser.open` | 事实核验 | 打开候选原文，确认发表时间、正文事实、数字口径；打不开标「无法核验」 |
| `social.search` | 补充发现 | 捕捉行业讨论与平台动态线索；线索必须回到可核验来源才可入池 |
| 定向域名搜索 | 官方与垂类优先 | 对官方站、垂类媒体站内检索当期内容 |

## 2. 查询矩阵（继承原 fixed_queries + gap_search）

每天（或每次运行）按四组执行，窗口优先最近 24–72 小时，另维护 7 天回溯处理迟发现：

**平台组**
- 即时零售 美团闪购 京东到家 最新动态
- 即时零售 淘宝闪购 抖音小时达 最新政策
- 即时零售 屈臣氏 美妆个护 最新合作
- 前置仓 / 闪电仓 即时零售 美妆 最新消息

**竞对组**
- 丝芙兰 即时零售 最新动态
- 万宁 即时零售 最新布局
- 调色师 美团闪购 最新投入
- 话梅 妍丽 即时零售

**品类组**
- 美妆个护 即时零售 GMV 增长 数据
- 防晒 即时零售 销量 趋势（按季节调整：秋冬换护肤/保湿/彩妆大促）
- 护肤 即时零售 增长 最新
- 面膜 即时零售 爆款

**渠道组**
- 屈臣氏 电商 渠道变化 最新
- 美妆个护 前置仓 渠道 最新
- 即时零售 美妆 品牌入驻 新品

**缺口补搜**：某平台当日无有效事件时，对该平台最多补搜 3 条定向 query（沿用原 gap_search 各平台词表：美团闪购、京东秒送/到家、淘宝闪购/饿了么、抖音小时达）。

**验证搜索**：对屈臣氏相关度高但置信度低/中的候选，反查最多 2 条 query 交叉核对（沿用原 verify_search 规则）。

组合原则：「平台动作 × 品牌/品类 × 竞对 × 商业变量（补贴、抽佣、流量分配、履约、货盘、会员）」交叉组合，避免单一泛关键词。

## 3. 来源分层与使用顺序

1. **官方优先**：美团、京东、阿里（淘宝闪购/饿了么）、抖音电商官方发布；品牌官方；NMPA 及地方药监、市场监管总局公告。
2. **可信商业媒体**：晚点、36氪、财新、界面、虎嗅、华尔街见闻。
3. **垂类媒体**：亿邦动力、联商网、品观、聚美丽、青眼、CBNData、化妆品观察、零售商业评论等。
4. **搜索发现层**：聚合与转载仅作线索，必须回溯到 Tier≥3 来源或官方原文才可支撑 P0/P1。

全局噪音排除（继承原 exclude_domains 思路）：知乎、百度系、微博、豆瓣及电商商品页域名不作为证据来源。

## 4. 每次运行的覆盖自检（必须记录）

- 检查了哪些平台/竞对/品类维度，各维度候选数；
- 哪些来源打不开或无法核验，原因；
- 官方来源是否有当期发布（无也要记录「已查无」）；
- 遗漏风险：哪些关键平台本期零覆盖，是否已执行缺口补搜。

## 5. 来源有效性复盘（持续）

在 OPERATIONS 复盘中记录：各来源实际贡献的 P0/P1 事件数、无独特贡献的来源、新增可信来源。搜索策略可据此调整；业务边界不可因此突破。
